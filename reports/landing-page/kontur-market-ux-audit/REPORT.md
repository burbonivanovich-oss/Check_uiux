# UX-аудит kontur.ru/market — краткий итоговый отчёт

**Дата:** 2026-04-27
**Объём:** 14 страниц (хабы, отрасли, оборудование, ОФД, тарифы, госсистемы)
**Метод:** Playwright-захват HTML/скриншотов через GitHub Actions relay → 14 параллельных подагентов-аналитиков (CRO-методология) → синтез

---

## 1. Карта страниц и их роли

| Тип | Страницы | Роль в воронке |
|---|---|---|
| **Хабы** | `/market`, `/price-group/`, `/price/` | вход с рекламы/SEO, выбор отрасли |
| **Отраслевые** | `/roznitsa-loyalnost`, `/obshepit-loyalnost`, `/uslugi` | прогрев по сегменту |
| **Функциональные** | `/gossistemy` (ЕГАИС, маркировка, Меркурий) | прогрев по «обязательной» боли |
| **Оборудование** | `/kkt`, `/kkt/mspos-f20-f`, `/fn`, `/kits` | продажа железа |
| **Сервисные** | `/ofd-directoru`, `/price-setting-kkt` | допродажа ОФД/услуг |
| **Тарифы** | `/price-gossistemy` | финальный шаг — выбор тарифа |

## 2. Ключевые пользовательские пути и пробелы

### Путь A. «У меня магазин, нужна онлайн-касса с 54-ФЗ»
`/market` → `/roznitsa-loyalnost` → `/kkt` → `/kkt/mspos-f20-f` → `/fn` → `/price/` → форма
**Пробелы:**
- На `/market` нет вопроса «у вас уже есть касса?» — пользователь не понимает, нужен ли ему ФН отдельно или комплект.
- Между `/kkt` и `/kkt/mspos-f20-f` нет помощника выбора модели (3+ моделей без сравнения).
- `/fn` не связан с конкретной кассой — пользователь не знает, какой ФН подходит к F20.
- 4 разных страницы цен (`/price/`, `/price-group/`, `/price-gossistemy`, `/price-setting-kkt`) — путается, какая «настоящая».

### Путь B. «У меня кафе/общепит»
`/market` → `/obshepit-loyalnost` → `/kkt` → `/kits` → форма
**Пробелы:**
- `/obshepit-loyalnost` сфокусирован на лояльности, а не на ЕГАИС/Меркурии — для общепита это критично, ссылки на `/gossistemy` нет в hero.
- `/kits` показывает «готовые комплекты», но не объясняет, какой комплект под общепит vs розницу.

### Путь C. «Нужна маркировка / ЕГАИС / Меркурий»
SEO → `/gossistemy` → `/price-gossistemy` → форма
**Пробелы:**
- `/gossistemy` смешивает 3 разных системы в одной странице без табов/якорей — нельзя быстро прыгнуть к «своей» проблеме.
- На `/price-gossistemy` тарифы названы по модулям, но без расшифровки «что входит» — нужно скроллить.

### Путь D. «Я директор, мне нужен ОФД»
`/ofd-directoru` → `/price/` → форма
**Пробелы:**
- `/ofd-directoru` написан языком «для директора», но CTA ведёт на ту же общую форму, что и для бухгалтера — нет персонализации.
- Нет калькулятора стоимости ОФД по числу касс.

### Путь E. «Сравниваю цены»
Реклама → `/price-group/` → `/price/` или `/price-gossistemy`
**Пробелы:**
- 4 страницы цен с разной логикой; пользователь не понимает, где итоговая стоимость «всё включено».
- Цены в формате «от X ₽ за 3 мес за торговую точку» — нестандартная единица, сравнить с конкурентами невозможно.
- Калькулятора итоговой стоимости нет ни на одной странице.

## 3. Что нужно поменять в путях (Task 1+2)

**Приоритет 1 — структура воронки:**
1. **Свернуть 4 страницы цен в 2:** `/price/` (модули + калькулятор) и `/price-gossistemy` (только госсистемы). `/price-group/` и `/price-setting-kkt` — редиректы.
2. **Добавить квиз-помощник** на `/market` (3 шага: отрасль → есть ли касса → нужны ли госсистемы) → персонализированная посадка.
3. **Связать `/kkt/<модель>` с `/fn`**: на странице кассы — блок «совместимые ФН» с прямой кнопкой добавления.
4. **На `/gossistemy` сделать табы** ЕГАИС / Маркировка / Меркурий с deep-link якорями.

**Приоритет 2 — связи между страницами:**
5. На `/obshepit-loyalnost` добавить блок «Если вы продаёте алкоголь / молочку — нужны госсистемы» → `/gossistemy`.
6. На отраслевых страницах добавить «следующий шаг»-блок с конкретной моделью кассы и комплектом.
7. На `/kits` добавить фильтр «для розницы / общепита / услуг» в hero.

**Приоритет 3 — единый CTA:**
8. Унифицировать: «Купить» на оборудовании, «Подключить» на сервисах, «Получить расчёт» на тарифах. Сейчас «Заказать / Отправить заявку / Купить» используются вперемешку.

## 4. Проблемы конверсии по каждой странице (Task 3)

### `/market` (главный хаб)
- Hero без CTA — только заголовок и иллюстрация.
- Нет квиза/помощника выбора.
- Социальное доказательство отсутствует (нет логотипов клиентов, отзывов, цифр).

### `/roznitsa-loyalnost`
- URL обещает «лояльность», hero — про кассу. Несовпадение.
- Длинная форма (регион + ИНН + КПП) на первом экране.
- Нет кейсов розничных клиентов.

### `/obshepit-loyalnost`
- То же несоответствие URL/контента.
- Нет упоминания ЕГАИС/Меркурия — критично для общепита.
- Кнопка «Заказать» без объяснения, что произойдёт после.

### `/uslugi`
- Самая «голая» страница: hero + форма, без объяснения сценариев (парикмахерская vs автосервис vs репетитор).
- Нет примеров «как настроить под свой бизнес».

### `/gossistemy`
- 3 системы на одной странице без навигации.
- Hero без CTA.
- Цены не показаны — пользователь уходит на `/price-gossistemy`, теряя контекст.

### `/kkt` (хаб касс)
- Список моделей без сравнительной таблицы.
- Нет фильтра «по типу бизнеса / по бюджету».
- Соцдоказательства нет.

### `/kkt/mspos-f20-f`
- Технические характеристики без перевода на язык выгод.
- Нет «совместимый ФН» блока.
- Цена есть, но без расчёта «касса + ФН + ОФД».

### `/kits`
- «Готовые комплекты» без указания, под какой бизнес.
- Нет сравнения комплектов между собой.
- CTA «Заказать» ведёт в общую форму без привязки к выбранному комплекту.

### `/ofd-directoru`
- Текст «для директора», но форма та же общая.
- Нет калькулятора по числу касс.
- Нет блока «что входит в ОФД».

### `/fn`
- Не связан с конкретными моделями касс.
- Нет помощника «какой ФН мне нужен» (15 / 36 мес).
- Цены без объяснения разницы.

### `/price-setting-kkt`
- Услуга «настройка ККТ» подаётся как тариф, но это разовая услуга.
- Нет описания, что именно входит в настройку.
- Нет указания сроков выполнения.

### `/price-group/`
- Дубль `/price/` с другой подачей — путает.
- Нет явного «начать здесь».

### `/price/`
- Цены в формате «от X ₽ за 3 мес за торговую точку» — нестандарт.
- Нет калькулятора итоговой стоимости.
- Нет сравнения тарифов в таблице.

### `/price-gossistemy`
- Тарифы по модулям без расшифровки «что входит».
- Нет связи «у меня уже есть Контур.ОФД — будет ли скидка».
- Форма та же общая.

## 5. Системные проблемы (повторяются на 10+ страницах)

1. **Нет соцдоказательства** (13/14 страниц): ни логотипов клиентов, ни отзывов, ни цифр «X тыс. подключённых».
2. **Длинные формы** на первом экране: регион + ИНН + КПП — отпугивают.
3. **Hero без CTA** (6 страниц): пользователь должен скроллить, чтобы понять, куда жать.
4. **Конкурирующие CTA**: «Купить / Заказать / Отправить заявку» вперемешку.
5. **Нет калькулятора** итоговой стоимости (касса + ФН + ОФД + тариф).
6. **Нестандартные единицы цен** («от X ₽ за 3 мес за торговую точку») — сравнить с конкурентами невозможно.
7. **4 страницы цен** — пользователь не понимает, где итог.
8. **URL/контент несоответствие** на `/roznitsa-loyalnost`, `/obshepit-loyalnost`, `/price-group/`.
9. **Нет помощников выбора** (квиз / фильтр) — на хабах и моделях касс.
10. **Нет связи между страницами** оборудования (касса ↔ ФН ↔ комплект).
